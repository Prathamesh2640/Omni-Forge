# OmniForge

> Developer's Unified Automation Forge

OmniForge is a cross-platform, fully offline, modular developer automation suite built on a Micro-Kernel Plugin Registry architecture. It provides engineers, architects, and DevOps practitioners with a single unified desktop application — replacing scattered terminal commands, ad-laden online converters, and memory-intensive IDE plugins.

**Platform:** Windows 10+ | Ubuntu 20.04+ | macOS 12+  
**Python:** 3.11+  
**Architecture:** Micro-Kernel Plugin Registry (NiceGUI / FastAPI)  
**Status:** In Development — Architecture Phase
